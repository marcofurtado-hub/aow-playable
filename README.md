# Ashes of War · Metagame Lab

The metagame UX study in one page: today's build redrawn screen by screen (Explain mode says what every button does), the proposal, Today × Proposal, flow maps with live tap counts, and a free-form editor.

On this public copy your changes stay in your browser (export JSON to share them). The full version — cloud saving, variants for the team, and AI generation with Claude and Layer — is the Claude artifact.

Built with Claude Code. Source: `UI/metagame-lab-site/` (run `python3 build.py`).
